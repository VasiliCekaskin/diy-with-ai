## Google Search Console / basic SEO — reviewed 2026-11-19

- [About Search Console](https://support.google.com/webmasters/answer/9128668?hl=en): free, owner-account service for crawl/index/search-performance checks; not required for inclusion in Search.
- [Property setup](https://support.google.com/webmasters/answer/34592?hl=en) and [ownership verification](https://support.google.com/webmasters/answer/9008080?hl=en): Domain properties cover protocols/subdomains and use DNS; exact URL-prefix properties offer HTML file/tag verification. Keep proof after success. Add only Google's actual record at authoritative DNS with customer approval, preserve email/other TXT, no nameserver changes or unnecessary permissions.
- [Cloudflare DNS records](https://developers.cloudflare.com/dns/manage-dns-records/how-to/create-dns-records/): DNS Records > Add record > type and actual values > Save. Use the actual DNS host, which may differ from registrar.
- [Sitemap report](https://support.google.com/webmasters/answer/7451001?hl=en) and [sitemap creation](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap): submit a real accessible sitemap address; success is fetching/parsing rather than indexing. A sitemap isn't mandatory for a small well-linked site. Use final public URLs, excluding previews/private content.
- [URL Inspection](https://support.google.com/webmasters/answer/9012289?hl=en): stored index information differs from a live test; requests/live tests do not guarantee indexing or ranking. Record pending states and revisit Pages/Indexing and Performance later.
- [SEO starter guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide): basic titles, descriptions, internal links and crawlability; advanced campaigns outside current scope. No Google account or live verification/indexing request was performed during implementation.
